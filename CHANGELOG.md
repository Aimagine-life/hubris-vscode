# Changelog

## 0.1.0

- Hubris models in GitHub Copilot Chat: chat, tool calling for agent mode, image input.
- Sign in through the browser (OAuth with PKCE), or use an API key.
- Balance in the status bar with a menu: top up, usage, sign out.
- Top up button when the balance runs out.
- Prompt caching for Anthropic models.
- `hubris.models` setting to choose which models appear in the picker.
- English and Russian interface.
